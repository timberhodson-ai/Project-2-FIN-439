0:35–1:10 · Where the sidebar input goes (app.py, lines 15–20)

This checkbox controls which months the app uses to estimate returns and risk. When I check it, last_36 becomes true. The app passes that setting into run, along with the annual cost, the EEM cap, and the VOO return adjustment. The app also calculates a separate reference portfolio using the defaults, so there’s a consistent baseline for measuring how much the weights move.

1:10–2:10 · How prices become portfolio estimates (analysis.py, line 18; portfolio.py, lines 162–164)

This function reads the saved monthly prices and calculates the return from one month to the next. If the box is checked, it keeps the last 36 monthly returns before estimating each ETF’s return and volatility and how the ETFs move together.

That matters because a shorter window can change both the return estimates and which ETFs provide diversification. The code then subtracts the selected annual cost from the return estimates and evaluates the portfolios under the selected assumptions.

2:10–3:15 · How the optimizer picks a portfolio (portfolio.py, line 125; analysis.py, line 39)

This loop works through portfolios in five-percentage-point steps. The weights add up to 100 percent, and the search skips mixes that break the weight limits or miss the seven percent estimated net return hurdle. Among the mixes that qualify, it keeps the one with the lowest estimated volatility.

The app also displays equal weight and inverse volatility so the committee can see how simpler approaches compare. These checks explain why a portfolio passes or fails. In the default case, both baselines clear the return hurdle but hold too little VOO, so the app gives the specific reason for each failure.

3:15–4:35 · Run the test live

With the full window, the selected portfolio is 70 percent VOO and 30 percent EEM. Now I’ll change only the window. The portfolio moves to 80 percent VOO and 20 percent EEM. Each of those holdings moves by ten percentage points, so the largest move is ten.

That’s below my 15-point stop threshold, so the paper-pilot decision holds in this test. The allocation still moved enough to matter. That’s why I’d monitor how sensitive the weights are to the choice of data window, and why I’d want evidence from new data before using live capital.
