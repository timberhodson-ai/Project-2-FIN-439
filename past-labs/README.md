# Prior lab work behind the Capstone

These copies trace the investment workflow back to the course labs. Lab 15 is the direct source of the ETF analysis. The other labs document methods that informed it. The Capstone uses its own saved data and settings, so the training cases in these reports may differ from the current app.

| Lab | Contribution |
|---|---|
| [Lab 13](Lab%2013.md) | Background for expressing mandate rules as explicit pass/fail checks. |
| [Lab 14](Lab%2014.md) | Equal-weight and inverse-volatility comparisons, covariance-based risk estimates, and mandate verdicts. |
| [Lab 15](Lab%2015.md) | Source for the ETF universe, allocation limits, estimation windows, constrained portfolio search, and initial 70% VOO / 30% EEM mix. |
| [Lab 16](Lab%2016%20Point-in-Time.md) | Background for checking whether evidence was available by the decision date. |
| [Lab 17](Lab%2017%20Rates%20and%20Vintages.md) | Background for separating observation dates from release and vintage availability. |

The corporate component comes from the [Project 1 ADP DCF](../docs/ADP_project_DCF.md). The [Capstone README](../README.md) explains how to run the integrated app, and the [executed output](../docs/visible-output.md) shows the results for the saved snapshots.
